# 조각 5 — standalone-mobile-app (2026-10-28 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- 지금까지 만든 영어 첨삭(조각 1) · 단어장 복습(조각 2) · 연속 학습 루틴(조각 3) · 오늘의 상황별 미션(조각 4)을 스마트폰 앱으로 언제 어디서든 쓰고 싶지만, 매번 PC 파이썬 서버를 켜두거나 유료 클라우드 서버를 운영하기는 번거롭다.
- 별도 백엔드 서버 없이도 스마트폰 기기 자체에 내 학습 데이터(단어장, 첨삭 기록, 연속 학습 루틴)와 개인 Gemini API 키를 안전하게 저장하고, 모바일 앱(PWA / Android 패키지)으로 설치해 단독 실행할 수 있어야 한다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(1인 모바일·PC 학습자)
- 시나리오:
  1. **서버 없이 스마트폰 단독 실행 (온디바이스 엔진 자동 동작)**:
     - 파이썬 서버가 연결되지 않은 환경(모바일 앱 단독 실행, 오프라인, 정적 호스팅)에서도 첨삭 · 단어장 복습 · 루틴 달력 · 오늘의 미션 기능이 스마트폰 기기 내부 저장소(`localStorage`)를 통해 100% 동일하게 동작한다.
  2. **앱 내 `[⚙️ 모바일 앱 · 설정]` 탭에서 API 키 설정 및 학습 데이터 백업/복원**:
     - 코드에 키를 하드코딩하지 않고, 앱의 설정 화면에서 내 Gemini API 키를 입력해 스마트폰 기기 내부에만 저장하거나 삭제한다(키를 설정하면 스마트폰에서 직접 Gemini API를 호출하고, 키가 없거나 오프라인이면 내장 스마트 코치가 즉시 3단 첨삭을 제공한다).
     - 기기 변경이나 PC↔스마트폰 간 이동을 위해 **[💾 내 학습 데이터 백업 파일(.json) 다운로드]** 및 **[📂 백업 파일 불러오기(복원)]** 기능으로 단어장·첨삭 기록·루틴 설정을 언제든 옮길 수 있다.
  3. **모바일 앱 설치 (PWA 매니페스트 · 서비스 워커 · 앱 아이콘)**:
     - 스마트폰 브라우저나 패키징 도구(Capacitor / PWA Builder)에서 앱 아이콘, 전체 화면(`standalone`), 오프라인 캐시를 갖춘 모바일 앱으로 바로 설치해 사용한다.

## 성공 기준

- 파이썬 서버 없이 정적 파일(`public/` 폴더)만으로도 조각 1~4의 모든 API 요청(`/api/feedback`, `/api/history`, `/api/vocab`, `/api/vocab/review`, `/api/routine`, `/api/routine/goal`, `/api/mission/today`)이 클라이언트 온디바이스 엔진(`public/standalone-engine.js`)을 통해 처리된다.
- `[⚙️ 앱 설정 · 백업]` 탭에서 Gemini API 키를 기기 내에 저장·초기화할 수 있으며, 코드나 저장소에는 API 키가 일절 포함되지 않는다.
- 학습 데이터 전체(첨삭 기록, 단어장, 루틴 목표 및 복습 로그)를 JSON 백업 파일로 내보내고, 백업 파일을 다시 불러올 때 데이터 형식을 검증해 안전하게 복원한다.
- 웹 앱 매니페스트(`public/manifest.webmanifest`), 모바일 앱 아이콘(`public/icon.svg`), 오프라인 서비스 워커(`public/sw.js`)가 제공되어 모바일 앱 설치 규격을 충족한다.

## 하지 않을 일

1. 외부 유료 클라우드 DB나 회원가입·로그인 서버를 도입하지 않는다.
2. 개인 Gemini API 키를 소스 코드나 GitHub 저장소에 절대 하드코딩하지 않는다.
3. 기존 PC 로컬 서버(`python -m src.app`) 동작을 깨뜨리지 않는다(PC 서버 실행 시 서버 우선 또는 온디바이스 모드 선택 가능).

## 제약

- 스택 · 비용: 순수 표준 웹 기술(Vanilla JS, Web Storage API, Service Worker, Web App Manifest) 및 기존 Python 3.14 표준 라이브러리 서버 호환 유지, 비용 0원.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 구현 완료 후 — `audit-secrets`(모바일 앱 설정의 API 키 취급 및 하드코딩 부재 점검) · `audit-data`(온디바이스 저장소 및 JSON 백업·복원 무결성 점검) · `audit-contract`(온디바이스 엔진과 기존 API 응답 규약 일치 점검)

## 닫으며 (2026-10-28)

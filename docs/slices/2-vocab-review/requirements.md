# 조각 2 — vocab-review (2026-10-27 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- AI 첨삭을 통해 좋은 원어민 표현과 핵심 단어를 배워도, 따로 모아두고 주기적으로 다시 떠올려 보지 않으면 며칠 뒤에 금방 잊어버린다.
- 외우고 싶은 표현만 골라 내 단어장에 원클릭으로 담고, 내가 얼마나 잘 기억하는지(몰랐음 · 헷갈림 · 쉬웠음)에 따라 복습 날짜가 자동으로 잡히는 학습 흐름이 필요하다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(1인 학습자)
- 시나리오:
  1. **단어장에 담기**:
     - AI 첨삭 결과 화면의 ② 추천 표현 및 ③ 핵심 단어·표현 옆에 있는 **[+ 단어장에 담기]** 버튼을 눌러 외우고 싶은 표현을 즉시 저장한다.
     - 또는 단어장 영역에서 내가 직접 외우고 싶은 영어 표현·한국어 뜻·예문을 입력해 추가한다.
  2. **오늘의 복습 카드 학습**:
     - **오늘 복습할 표현** 카드를 열면 먼저 **한국어 뜻(과 예문 힌트)**이 보인다.
     - 머릿속으로 영어 표현을 떠올려 본 뒤 **[정답 보기]** 버튼을 누르면 정답 영어 표현과 전체 예문이 나타난다.
     - **[몰랐음 (1일 뒤)]** · **[헷갈림 (3일 뒤)]** · **[쉬웠음 (7일→14일→30일 뒤)]** 버튼 중 하나를 누르면 다음 복습 날짜가 자동으로 갱신되고 다음 복습 카드로 넘어간다.
  3. **전체 단어장 관리**:
     - 내가 저장한 전체 단어·표현 목록과 각 표현의 다음 복습 예정일·복습 횟수를 한눈에 확인하고, 필요 없는 항목은 삭제할 수 있다.

## 성공 기준

- AI 첨삭 결과 카드에서 **[+ 단어장에 담기]** 클릭 한 번으로 단어장에 저장되며, 이미 담긴 표현은 중복 저장되지 않고 안내된다.
- 직접 입력 폼을 통해서도 새 영어 표현·한국어 뜻·예문을 단어장에 추가할 수 있다.
- 오늘 복습할 대상(복습 예정일이 오늘 이전이거나 새로 추가되어 즉시 복습 가능한 항목)이 카드 퀴즈(뜻 먼저 보기 → 정답 확인 → 난이도 3단계 선택)로 동작한다.
- 난이도 선택 결과(`again` / `hard` / `easy`)에 따라 다음 복습 예정일이 `1일 뒤` / `3일 뒤` / `7일→14일→30일 뒤`로 정확히 계산되어 내 PC(`data/vocab-items.json`)에 자동 저장된다.

## 하지 않을 일

1. 외부 사전 API 연동이나 발음 오디오 파일 별도 생성은 하지 않는다.
2. 일일 연속 학습일(스트릭) 달력 및 주간 학습 통계 대시보드는 이번 조각에서 만들지 않는다(3번 조각 `study-routine` 범위).
3. 다른 사용자와의 단어장 공유·내보내기 기능은 넣지 않는다.

## 제약

- 스택 · 비용: 1번 조각과 동일한 Python 3.14 표준 라이브러리 로컬 서버 및 로컬 JSON 파일(`data/vocab-items.json`)을 사용하며 추가 외부 유료 서비스는 쓰지 않는다.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 구현 완료 후 — `audit-data`(단어장 저장 구조 및 복습 주기 상태 갱신의 무결성 점검) · `audit-contract`(단어장 추가·조회·복습 API 요청·응답 규약 점검)

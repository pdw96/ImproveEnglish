## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **[V1] 단어장 입력 검증 및 중복 방지**: 영어 표현(`expression`)과 한국어 뜻(`meaning`)이 비어 있거나 길이 상한(표현 200자, 뜻 300자, 예문 500자)을 넘으면 `400 Bad Request`로 거절한다. 이미 같은 영어 표현(대소문자·앞뒤 공백 무시)이 단어장에 있으면 중복 생성하지 않고 기존 항목을 안내한다.
- **[V2] 난이도 3단계 복습 주기(SRS) 계산 보장**:
  - 처음 단어장에 담은 표현은 **오늘 바로 복습 가능**(`nextReviewDate <= 오늘`) 상태로 시작한다.
  - 복습 평가(`rating`) 선택 시 다음 복습 예정일(`nextReviewDate`)과 연속 성공 단계(`box`: 0~3)를 다음과 같이 계산한다:
    - `again` (몰랐음): `box = 0`, **1일 뒤** 복습
    - `hard` (헷갈림): `box = max(1, 현재 box)`, **3일 뒤** 복습
    - `easy` (쉬웠음): `box`를 1단계 올려 1단계면 **7일 뒤**, 2단계면 **14일 뒤**, 3단계 이상이면 **30일 뒤** 복습
- **[V3] 로컬 자동 저장 및 원자적 갱신**: 단어 추가·복습 평가·삭제 결과는 내 PC의 `data/vocab-items.json`에 임시 파일 교체 방식으로 안전하게 저장되어 브라우저를 새로고침해도 유지된다.

**보장하지 않는 것(알려진 한계)**

- 복습 예정일 기준은 내 PC의 날짜(YYYY-MM-DD)를 따르며, PC 시스템 시계를 임의로 바꾸면 복습 대상 표시 시점도 함께 바뀐다.

## ③ 받는 입력

- **단어 추가 입력 (`POST /api/vocab`)**:
  - `expression` (문자열, 필수): 공백 제외 1자 ~ 200자 영어 단어·숙어·문장.
  - `meaning` (문자열, 필수): 공백 제외 1자 ~ 300자 한국어 뜻 또는 뉘앙스 설명.
  - `example` (문자열, 선택, 기본값 `""`): 최대 500자 영어 예문.
- **복습 평가 입력 (`POST /api/vocab/review`)**:
  - `id` (문자열, 필수): 단어장 항목 ID.
  - `rating` (`"again"` | `"hard"` | `"easy"`, 필수): 내가 선택한 기억 난이도.
- 위 조건을 벗어난 입력은 `400 Bad Request`(존재하지 않는 ID는 `404 Not Found`)와 한국어 안내 메시지로 거절한다.

## ④ 결정

**정한 것 (업무에 영향이 없는 기술 결정 — 추천안으로 확정)**

- **화면 구성**: 복잡한 페이지 이동 없이 한 화면에서 바로 오갈 수 있도록 상단 탭(**[✨ AI 영작·말하기 첨삭]** 탭 / **[📚 내 단어장 · 오늘의 복습]** 탭)으로 구성하되, 첨삭 결과 카드에서 **[+ 단어장에 담기]**를 누르면 즉시 단어장 배지 숫자가 올라가도록 연결한다.
- **처음 담은 단어의 복습 시점**: 오늘 배운 표현을 당일 바로 한 번 테스트해 볼 수 있도록 신규 등록 시 `nextReviewDate`를 오늘 날짜(`YYYY-MM-DD`)로 설정한다.
- **저장 파일 분리**: 1번 조각의 첨삭 기록(`data/feedback-history.json`)과 섞이지 않도록 단어장 데이터는 `data/vocab-items.json`에 별도로 저장한다(`data/` 폴더 전체가 이미 `.gitignore`에 포함되어 개인 학습 데이터가 보호됨).

## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **[V1] 암호화 보관** — 비밀번호(4자 이상)와 함께 저장하면 `localStorage` 에 평문 키가 남지 않고 암호문 · 소금 · 초기값만
  남는다. 저장할 때마다 소금(16바이트)과 초기값(12바이트)을 새로 뽑는다.
- **[V2] 해제** — 맞는 비밀번호만 키를 되살린다. 틀린 비밀번호 · 망가진 저장 값은 해제하지 않고 저장 값을 지우지 않는다.
- **[V3] 해제 범위** — 해제한 키는 그 창(탭)의 `sessionStorage` 와 메모리에만 있다. 새로고침은 유지하고, 창을 닫으면 사라진다.
- **[V4] 잠김 표시와 첨삭** — 잠긴 동안 설정 탭 배지 · 안내 줄이 잠김을 보이고, 첨삭 요청은 내장 스마트 코치가 답한다. (PR 1)
- **[V5] 비밀번호 길이** — 비밀번호가 1 ~ 3자면 저장하지 않는다. 빈 비밀번호는 평문 보관(조각 standalone-mobile-app 호환). (PR 1)
- **[V6] 삭제** — **[키 삭제]** 는 평문 키 · 암호문 · 소금 · 초기값 · 해제 상태 다섯 값을 모두 지운다.
- **[V7] 백업 밖** — 학습 데이터 백업 파일에는 V1 · V3 의 값이 들어가지 않는다.

**보장하지 않는 것(알려진 한계)**

- **짧은 비밀번호는 저장소를 통째로 가져간 사람을 막지 못한다.** 4자리 숫자 비밀번호는 1만 가지뿐이라, 기기 저장소를 복사해 간
  사람이 다 대 보면 짧은 시간에 풀린다. 금고가 막는 것은 「폰을 잠깐 빌린 사람이 저장소를 훑어보는 것」이다. 긴 비밀번호일수록
  강하다.
- **해제된 동안 키는 그 창의 `sessionStorage` 에 평문으로 있다.** 해제한 창을 연 채 폰을 남에게 주면 개발자 도구 등으로 키가
  보인다(`a62f59a` 가 편의를 위해 고른 것 — ④).
- 같은 사이트에 남의 스크립트가 끼어들면(XSS) 해제된 키를 읽을 수 있다 — 금고는 그 경계가 아니다.
- 저장 값이 망가진 경우와 비밀번호가 틀린 경우를 가르지 않는다 — 둘 다 「일치하지 않습니다」로 보인다.
- 브라우저의 사이트 데이터를 지우면 금고도 함께 지워진다.

## ③ 받는 입력

- **설정 탭 입력** — 앞뒤 공백을 지운 두 문자열.
  - `apiKey` 있음 · `pin` 빈 문자열 → 평문 보관
  - `apiKey` 있음 · `pin` 4자 이상 → 암호화 보관
  - `apiKey` 있음 · `pin` 1 ~ 3자 → 거절 (PR 1)
  - `apiKey` 빈 문자열 · `pin` 있음 · 금고 있음 → 해제 시도
  - 그 밖(둘 다 빈 문자열 등) → 「저장할 Gemini API 키를 입력해 주세요」
- **기기 저장 값** — `ie_gemini_api_key_salt` · `ie_gemini_api_key_iv` · `ie_gemini_api_key_encrypted` 는 0 ~ 255 정수 배열의
  JSON. JSON 이 아니거나 복호화가 실패하면 해제하지 않는다(V2).

## ④ 결정

이 레포는 ADR 을 두지 않는다 — 대안이 있던 결정의 근거를 여기 적는다(조각 1 ~ 5 와 같다).

**정한 것**

- **PBKDF2(SHA-256, 100,000회) + AES-256-GCM, 브라우저 내장 Web Crypto** — 대안: 평문 유지(폰 열람에 무방비), 외부 암호
  라이브러리(의존성 · 배포 파일 증가). 저자가 `cb331a0` 에서 골랐다.
- **해제 상태를 창이 열린 동안 `sessionStorage` 에 유지** — 대안: 메모리에만 두고 새로고침마다 다시 묻기(더 안전하지만 매번
  번거롭다). 저자가 `a62f59a` 에서 편의를 골랐다 — 대가는 ② 의 두 번째 한계.
- **비밀번호 최소 4자** — 화면 안내 문구(「4자리 이상 비밀번호」)가 이미 약속한 길이에 코드를 맞춘다. 더 긴 최소 길이는 PIN
  습관과 맞지 않아 고르지 않았다.
- **시험은 Node 로 엔진을 실제로 돌린다** — 이 레포의 시험은 Python 이지만 암호화는 Web Crypto 에서만 돈다. Node 22 의
  `crypto.subtle` 이 같은 API 라, 시험이 `public/standalone-engine.js` 를 Node 에서 가짜 `localStorage` · `sessionStorage` 로
  불러 V1 ~ V3 · V5 · V6 를 실제로 본다. Node 가 없으면 그 시험은 건너뛰고 건너뛴 이유를 남긴다.

**열어 둔 것**

- 없음.

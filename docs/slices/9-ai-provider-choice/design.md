## ② 보장하는 것 / 보장하지 않는 것

**보장하는 것**

- **[P1] 고르기** — 고른 AI 는 ③ 의 닫힌 목록(`gemini` · `openai` · `anthropic`) 가운데 하나다. 폰 앱은 기기 저장소 `ie_ai_provider`, PC 는
  `.env` 의 `AI_PROVIDER` 에서 읽고, 없거나 목록 밖 값이면 `gemini` 다. 폰 앱에서 고른 것은 앱을 다시 열어도 남는다.
- **[P2] 고른 회사 하나만** — 첨삭 한 번 · AI 새 문제 한 번은 고른 회사 하나만 부른다. 그 회사 안의 모델 후보(지금 Gemini 처럼 HTTP 404 일 때
  다음 모델)만 넘어가고, 다른 회사는 부르지 않는다.
- **[P3] 같은 모양** — 어느 회사의 응답이든 지금의 검사(서버 `FeedbackResponse.from_dict` · 엔진의 첨삭 응답 검사 · 퀴즈의 AI 응답 검사)를
  지나야 쓴다. 첨삭 결과와 첨삭 노트에 남는 기록 모양은 이 조각 전과 같고, 어느 회사가 답했는지는 기록에 남지 않는다.
- **[P4] 실패하면 지금처럼** — 키 없음 · 금고 잠김 · 호출 실패 · 응답 검사 탈락이면:
  - 폰 앱 첨삭: 내장 스마트 코치(지금과 같음)
  - PC 첨삭: 크레딧 소진 · 한도 초과면 내장 스마트 코치, 그 밖은 키 값 없는 오류 안내(지금과 같음 — 안내 글의 회사 · 환경변수 이름만 고른 회사 것)
  - 퀴즈(두 모드): 그만큼 내 기록 문제로 채우고 지금의 안내(조각 review-quiz Q1 · Q9)
- **[P5] 금고 하나** (폰 앱) — 회사마다 키 칸이 있고 저장 · 지우기는 그 회사 키만 바꾼다. 금고는 비밀번호 하나로 **통째로** 잠기거나 열려 있다.
  - 잠긴 키가 하나라도 있을 때 새 키를 저장하려면 그 비밀번호를 넣어야 한다. 비밀번호가 없거나 맞지 않으면 거절하고 저장 내용 전체를 그대로 둔다.
  - 잠긴 키가 없을 때 비밀번호를 넣어 저장하면, 비밀번호 없이 두었던 다른 키도 같은 비밀번호로 함께 잠근다.
  - 비밀번호를 한 번 넣어 풀면 잠긴 키가 모두 풀린다(창이 열려 있는 동안 — 지금과 같음).
  - 비밀번호 길이 규칙(4자 이상)은 지금과 같다.
- **[P6] 옛 Gemini 키 그대로** (폰 앱) — 지금 기기에 있는 Gemini 키 저장 이름(`ie_gemini_api_key` · `_salt` · `_iv` · `_encrypted` · 창 보관
  `ie_gemini_api_key_session`)을 그대로 Gemini 칸으로 읽는다. 옮기거나 다시 쓰지 않는다 — 다시 넣지 않아도, 지금 비밀번호로 풀린다.
- **[P7] 키 안전** — 키는 회사마다 머리글로만 보낸다(Gemini `x-goog-api-key` · OpenAI `Authorization: Bearer` · Anthropic `x-api-key`).
  요청 주소 · 오류 안내 · 첨삭 기록 · 백업 파일에 키가 나오지 않는다. 회사 오류 글에 키가 섞여 오면 가린다(지금 Gemini 와 같음).
- **[P8] 로컬 서버는 자기 화면만** (PC) — `POST` · `DELETE` `/api/*` 요청에 `Origin` 머리글이 있고 그것이 그 요청의 `Host` 로 만든
  `http://<Host>` 와 다르면 403 「이 서버는 자기 화면에서 온 요청만 받습니다.」 를 돌려주고, 아무것도 저장하지 않고 AI 를 부르지 않는다.
  `Origin` 이 없는 요청은 지금처럼 받는다(조각 review-quiz 회차 18 OB-1 의 답).
- **[P9] 앵커볼트 그대로** — 첨삭 지시문 · 응답 스키마 상수(서버 · 엔진)와 퀴즈 지시문 · 스키마 상수가 이 조각 전과 글자까지 같다.
  기존 시험 117개가 그대로 통과한다.

**보장하지 않는 것(알려진 한계)**

- 첨삭 · 문제의 내용 품질과 말투는 회사마다 다를 수 있다 — 앱은 모양(③)만 검사한다.
- 회사가 모델 이름을 없애면 그 회사의 모든 후보가 실패해 P4 대로 돈다. 모델 후보를 고치는 것은 그때의 일이다.
- 폰 앱이 OpenAI · Anthropic 을 브라우저에서 직접 부르는 것은 그 회사가 브라우저 직접 호출(CORS)을 받아 줘야 된다. 막히면 P4 대로 돈다(④ 열어 둔 것).
- 키를 다른 회사 칸에 잘못 넣어도 앱은 알아채지 않는다 — 그 회사 호출이 실패해 P4 대로 돈다.
- 금고 비밀번호를 잊으면 키를 풀 수 없다 — 지금처럼 지우고 다시 넣는다.
- PC 와 폰 앱의 고른 AI · 키는 서로 따로다.
- 첨삭할 문장 · 퀴즈 재료(내 표현 최대 10개 · 최근 교정 문장 최대 3개)는 고른 회사로 간다 — 지금 Gemini 로 보내던 것과 같은 내용이다.

## ③ 받는 입력

- **고른 AI** — 닫힌 목록 `gemini` · `openai` · `anthropic`. 앞뒤 공백 정리 · 소문자로 맞춘 뒤 이 셋이 아니면 `gemini` 로 본다(P1).
- **키**
  - 폰 앱: 회사별 키 칸의 글. 앞뒤 공백을 정리하고, 비면 「키 없음」.
  - PC: `GEMINI_API_KEY` · `OPENAI_API_KEY` · `ANTHROPIC_API_KEY`. 비었거나 `.env.example` 의 자리표시 값(`your_..._here`)이면 「키 없음」.
  - 키 글의 앞머리(`AIza` · `sk-` 따위)는 검사하지 않는다(② 보장하지 않는 것).
- **금고 비밀번호** — 지금과 같다(빈 값 = 비밀번호 없이 저장, 1 ~ 3자 = 거절, 4자 이상 = 잠금). P5 의 「통째로」 규칙이 더해진다.
- **회사 응답에서 꺼내는 자리** — 꺼낸 글을 JSON 으로 읽어 P3 의 검사에 넘긴다. 아래 밖의 모양은 실패(P4)다.
  - Gemini: `candidates[0].content.parts[0].text` (지금과 같음)
  - OpenAI: `choices[0].message.content` — `refusal` 이 있으면 실패
  - Anthropic: `content[]` 의 첫 `text` 블록의 `text` — `stop_reason` 이 `end_turn` 이 아니면(`refusal` · `max_tokens` 따위) 실패

## ④ 결정

이 레포는 ADR 을 두지 않는다 — 대안이 있던 결정의 근거를 여기 적는다(조각 ai-feedback 부터 review-quiz 까지와 같다).

**정한 것**

- **의도 What 에 한 줄 · 앵커볼트는 꼴만 옮김** — 대안: 의도는 그대로 두고 범위 변경에만 적기. 저자가 2026-11-02 고른 것이다.
- **세 키를 다 넣어 두고 「지금 쓸 AI」로 고르기** — 대안: 한 번에 한 회사 키만. 저자가 2026-11-02 고른 것이다.
- **실패하면 내장 코치 · 내 기록, 다른 회사로 넘기지 않음** — 대안: 키가 있는 다른 회사로 자동 넘기기. 저자가 2026-11-02 고른 것이다
  — 고르지 않은 회사 요금이 나가지 않게.
- **회사마다 빠르고 싼 급 하나** — 대안: 회사별 최고급, 설정에서 급 고르기. 저자가 2026-11-02 고른 것이다. Gemini 는 지금 후보
  (`gemini-3.8-flash` → `gemini-flash-latest` → `gemini-2.5-flash`), Claude 는 `claude-haiku-5-5`, OpenAI 는 mini 급(이름은 열어 둔 것).
- **금고는 비밀번호 하나로 통째로** — 대안: 키마다 다른 비밀번호. 비밀번호가 여럿이면 잊기 쉽고, 첨삭 전에 풀기를 여러 번 해야 한다.
- **옛 Gemini 저장 이름을 그대로 쓴다** — 대안: 세 회사를 새 이름 한 묶음으로 옮기기. 옮기다 저장 공간 부족 등으로 멈추면 잠가 둔 키를
  잃을 수 있다. 새 두 회사만 같은 꼴의 새 이름(`ie_openai_api_key*` · `ie_anthropic_api_key*`)을 쓴다.
- **회사 호출을 서버 `src/ai_provider.py` 한 모듈 · 엔진 한 함수에 모은다** — 대안: 첨삭 · 퀴즈가 각자 회사별로 부르기. 조각 review-quiz
  ④ 가 「이 한 자리만 갈아 끼운다」고 남긴 자리다.
- **회사 SDK 없이 HTTP 로 직접 부른다** — 대안: OpenAI · Anthropic 공식 라이브러리. 서버는 지금까지 표준 라이브러리만 썼고(설치 없이 `python3`
  로 뜬다), 폰 앱은 빌드 도구 없는 브라우저 스크립트라 라이브러리를 실을 자리가 없다. 같은 이유로 지금 Gemini 도 직접 부른다.
- **JSON 응답은 각 회사의 「스키마로 묶은 출력」으로 받는다** — 대안: 지시문으로만 JSON 을 부탁하기. OpenAI 는 `response_format` 의
  `json_schema`, Anthropic 은 `output_config.format` 의 `json_schema` 로 지금 `RESPONSE_SCHEMA` · 퀴즈 스키마를 옮긴다(타입 이름 소문자화 등
  꼴만). 그래도 P3 의 검사는 그대로 문다.
- **온도(temperature)는 Gemini 에만 보낸다** — 대안: 세 회사에 같은 값. Anthropic 은 이 값을 받지 않고(보내면 400), OpenAI 의 mini 급
  추론 모델도 받지 않는 것이 있다. Gemini 의 첨삭 0.3 · 퀴즈 0.7 은 그대로다.
- **PC 는 `.env` 의 `AI_PROVIDER` 로 고른다** — 대안: 화면에서 골라 서버에 저장. 서버 모드의 첨삭 요청 모양(앵커볼트)에 회사를 싣지 않고,
  PC 키도 `.env` 에 있으니 한 자리에서 고친다. PC 서버 모드의 설정 탭은 「PC 는 `.env` 의 `AI_PROVIDER` 를 따릅니다」만 보인다.
- **로컬 서버 `Origin` 검사를 넣는다(P8)** — 대안: 지금처럼 두기. 키가 셋으로 늘면 다른 사이트가 내 키로 부를 수 있는 요금 길도 셋이 된다.
  `Host` 와 맞대는 꼴이라 포트 · 주소를 설정으로 따로 들지 않는다.
- **화면 자리** — 설정 탭의 지금 「02 키 설정 및 암호화 금고」 칸을 넓힌다: 맨 위 「지금 쓸 AI」 세 단추, 그 아래 회사별 키 칸 셋(칸마다
  상태 「없음 · 저장됨 · 잠김」과 [지우기]), 비밀번호 칸 하나와 [저장] 하나. 빈 키 칸은 저장 때 건드리지 않는다. 새 탭은 만들지 않는다.

**열어 둔 것**

- OpenAI 의 모델 이름(mini 급) · 요청 길(Chat Completions · Responses), Anthropic 요청의 생각 정도(`effort`) · `max_tokens`, 회사별로
  「크레딧 소진 · 한도 초과」로 볼 응답(P4 의 PC 첨삭) — PR 1 을 열기 전에 회사 문서로 정해 설계 끝 날짜 항목으로 적는다.
- OpenAI · Anthropic 이 폰 브라우저의 직접 호출(CORS)을 받는지 — PR 3 을 열기 전에 Chromium 에서 실제 주소로 확인한다(키 없이 401 응답의
  CORS 머리글로 본다). 막히면 그 회사를 폰 앱에서 어떻게 할지 저자에게 묻는다.

## ⑤ 검증 계획

- **저장소에 남기는 시험 — `tests/test_ai_provider.py`**
  - PC 서버 모드: `src/ai_provider.py` 와 `FeedbackApp` 의 첨삭 · 퀴즈 길을 가짜 전송 함수로 돈다(키 없이 돈다). 가짜 전송은 받은 주소 ·
    머리글 · 본문을 남겨, 시험이 「어느 회사로 무엇을 보냈나」를 본다. P8 은 `create_http_server` 를 실제로 띄워 `Origin` 을 바꿔 보낸다.
  - 단독 앱 모드: `tests/provider_harness.mjs` 가 Node 로 `public/standalone-engine.js` 를 가짜 브라우저 저장소 · 가짜 `fetch` 위에서 돌리고
    (조각 api-key-vault 의 `vault_harness.mjs` 와 같은 방식, 암호화는 Node 의 Web Crypto), `test_ai_provider.py` 가 판정한다. Node 가 없으면
    그 시험은 건너뛰고 이유를 남긴다.
  - **시험 규칙**
    - 보장(P1 ~ P9)마다 해당 모드 각각에서 시험 하나 이상 — P5 · P6 은 폰 앱만, P8 은 PC 만, 나머지는 두 모드.

## 2026-11-02 — PR 1 을 열기 전에 정한 것 (④ 열어 둔 것)

④ 의 열어 둔 것 가운데 PR 1 몫을 정한다. 위의 항목은 고치지 않는다. 업무에 영향이 없는 기술 결정이라 추천안으로 정했다(`Profile.md`).

- **OpenAI** — 요청 길은 Chat Completions(`POST https://api.openai.com/v1/chat/completions`, `response_format` 의 `json_schema` · `strict: true`).
  대안 Responses API 는 같은 일을 하지만, 지시문 · 사용자 글 두 줄로 끝나는 지금 요청에는 Chat Completions 가 꼴이 단순하다.
  모델 후보는 `gpt-5.4-mini` → `gpt-5-mini`(앞이 HTTP 404 면 뒤). 착공 때 OpenAI 공식 모델 목록 페이지는 이 작업 환경에서 열리지 않아
  (네트워크 허용 목록 밖) 검색 결과로 정했다 — 저자 기기 확인(⑤)에서 실제로 도는 모델을 닫는 기록에 적는다.
- **Anthropic** — `POST https://api.anthropic.com/v1/messages`, `anthropic-version: 2026-10-21`, 모델 `claude-haiku-5-5`,
  `output_config.effort: "low"`(첨삭 · 문제 만들기는 깊은 생각이 필요 없고 빨리 와야 한다), `max_tokens: 8000`(생각 토큰이 함께 세어져도
  응답이 잘리지 않게), 응답 꼴은 `output_config.format` 의 `json_schema`. 생각(thinking)은 이 모델의 기본(켜짐)을 그대로 둔다.
- **JSON 스키마 옮기기** — 두 회사 모두 같은 함수(`to_json_schema`)로 옮긴다. 타입 이름 소문자, 모든 객체에 `additionalProperties: false`,

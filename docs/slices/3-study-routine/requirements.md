# 조각 3 — study-routine (2026-10-28 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- 영어 문장 첨삭(조각 1)과 단어장 복습(조각 2)을 해도, 내가 며칠 연속으로 공부하고 있는지·오늘 정한 학습량을 채웠는지 한눈에 보이지 않으면 매일 꾸준히 이어가기 어렵다.
- 별도로 출석 체크를 누르는 번거로움 없이, 첨삭을 받거나 단어를 복습하면 자동으로 오늘의 학습 기록과 연속 학습일(스트릭)이 쌓이고 날짜별 공부 내역을 돌아볼 수 있는 루틴 관리 화면이 필요하다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(1인 학습자)
- 시나리오:
  1. **상단 루틴 배너로 오늘 학습 상태 즉시 확인**:
     - 웹 화면을 열면 상단 배너에서 **`🔥 연속 N일째 학습 중`** 배지와 **오늘의 공부 현황**(오늘 첨삭 M문장 / 목표, 오늘 단어 복습 K개 / 목표)을 항상 확인할 수 있다.
  2. **공부하면 자동으로 쌓이는 출석·루틴 기록**:
     - AI 첨삭을 1회 이상 받거나 단어장 복습을 1회 이상 완료하면 **오늘 학습 루틴 달성(출석)**으로 자동 기록되어 연속 학습일(스트릭)이 이어진다.
     - 내가 설정한 하루 목표(기본값: 첨삭 1문장, 복습 3단어)를 모두 채우면 **`🎉 오늘 목표 100% 달성!`** 배지가 켜진다.
  3. **내 학습 루틴 · 기록 탭에서 달력(잔디) 및 날짜별 공부 내역 확인·목표 변경**:
     - 상단 **`[🔥 내 학습 루틴 · 기록]`** 탭을 누르면 최근 14일 학습 달력(공부한 날·목표 달성한 날 표시), 최장 연속 학습일, 누적 학습일 통계를 한눈에 본다.
     - 달력의 날짜(또는 일자별 기록 목록)를 선택하면 그날 첨삭받은 문장과 복습·추가한 단어 내역을 모아 볼 수 있다.
     - 내 학습페이스에 맞춰 **하루 목표(첨삭 문장 수 1~20, 복습 단어 수 1~50)**를 언제든 바꾸고 저장할 수 있다.

## 성공 기준

- AI 첨삭(`POST /api/feedback`) 또는 단어 복습(`POST /api/vocab/review`)을 수행할 때마다 해당 날짜(`YYYY-MM-DD`)의 학습 활동이 자동으로 집계되어 연속 학습일(`currentStreak`)과 최장 연속 학습일(`longestStreak`)이 정확히 계산된다.
- 오늘(또는 어제까지) 연속으로 학습한 일수가 끊기지 않고 계산되며, 하루 이상 공백이 있으면 연속 학습일이 새로 시작된다.
- 하루 목표 설정(`POST /api/routine/goal`)을 통해 일일 목표 첨삭 수(1~20)와 일일 목표 복습 수(1~50)를 변경하면 내 PC(`data/routine-settings.json`)에 자동 저장되어 새로고침 후에도 유지된다.
- 화면 상단 배너와 `[🔥 내 학습 루틴 · 기록]` 탭에서 연속 학습일, 오늘 목표 진행률, 최근 14일 학습 달력, 날짜별 학습 상세 내역을 확인할 수 있다.

## 하지 않을 일

1. 이메일·모바일 푸시 알림이나 외부 캘린더(Google Calendar 등) 연동은 넣지 않는다.
2. 다른 사용자와의 랭킹 경쟁·리더보드 기능은 넣지 않는다.
3. 이미 저장된 과거 첨삭 기록이나 단어장 데이터를 임의로 수정·조작하는 기능은 넣지 않는다.

## 제약

- 스택 · 비용: 조각 1·2와 동일한 Python 3.14 표준 라이브러리 로컬 서버 및 로컬 JSON 파일(`data/routine-settings.json`, `data/vocab-items.json`, `data/feedback-history.json`)을 사용하며 외부 유료 서비스는 쓰지 않는다.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 구현 완료 후 — `audit-data`(루틴 목표·일별 학습 활동 집계 및 저장 무결성 점검) · `audit-contract`(루틴 조회·목표 설정 API 요청·응답 규약 및 하위 호환성 점검)

# 조각 4 — daily-mission (2026-10-28 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- 영작·말하기 첨삭 화면(조각 1)을 열어도 막상 오늘 어떤 주제로 문장을 써야 할지 막막해서 빈 입력창 앞에서 망설이게 된다.
- 내 단어장(조각 2)에 저장해 둔 표현들을 뜻 확인 복습으로만 그치지 않고, 실제 문장을 만들 때 직접 써보며 내 것으로 체화할 수 있는 연결 고리가 필요하다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(1인 학습자)
- 시나리오:
  1. **오늘의 상황별 미션 및 써볼 단어장 표현 확인**:
     - 첨삭 탭 상단에서 **오늘의 추천 상황 미션 카드**(한국어 상황 설명 + 영작 미션 주제 + 기본 힌트 표현)를 바로 확인한다.
     - 내 단어장에 저장된 단어(오늘 복습할 표현 우선, 없으면 최근 저장 표현 최대 2개)가 미션 카드 안에 **`💡 오늘 문장에 써볼 내 단어장 표현`**으로 함께 표시된다.
  2. **상황 카테고리 선택 및 다른 미션 뽑기**:
     - 원할 때 **[전체 · 비즈니스/업무 · 일상 대화 · 여행/외출 · 감정/의견]** 카테고리 버튼을 누르거나 **[🔄 다른 미션 보기]**를 눌러 내가 지금 연습하고 싶은 상황 미션으로 즉시 바꾼다.
  3. **추천 표현 칩 클릭 입력 및 미션 첨삭 완료**:
     - 미션 카드에 있는 기본 힌트 표현이나 내 단어장 표현 칩을 클릭하면 영작 입력창에 해당 표현이 바로 들어간다(또는 직접 문장을 작성·음성 입력한다).
     - **[첨삭받기]**를 완료하면 오늘의 미션 카드에 **`✅ 오늘 미션 완료!`** 배지가 켜진다.

## 성공 기준

- 오늘의 미션 조회(`GET /api/mission/today`) 시 오늘 날짜 기준으로 기본 추천 미션과 내 단어장에서 뽑은 추천 표현(최대 2개), 오늘 미션 완료 여부(`completedToday`)를 함께 반환한다.
- 카테고리(`all`, `work`, `daily`, `travel`, `opinion`) 필터나 다른 미션 선택(`missionId` 또는 다음 미션 요청)으로 상황별 미션을 즉시 전환할 수 있다.
- 미션 카드의 추천 표현(기본 힌트·내 단어장 표현)을 클릭하면 영작 입력창에 편리하게 삽입되며, 오늘 첨삭(`POST /api/feedback`)을 1회 이상 완료하면 미션 완료 상태(`completedToday = True`)가 표시된다.

## 하지 않을 일

1. 유료 외부 API를 추가로 호출해 매번 미션을 새로 생성하지 않는다(엄선된 내장 상황 미션 풀 + 내 단어장 연동으로 즉시 응답).
2. 미션을 수행하지 않았다고 해서 기존 첨삭 기능 이용을 막거나 강제하지 않는다.
3. 다중 사용자 간 미션 공유나 게시판 기능은 넣지 않는다.

## 제약

- 스택 · 비용: 조각 1~3과 동일한 Python 3.14 표준 라이브러리 로컬 서버 및 로컬 JSON 파일(`data/vocab-items.json`, `data/feedback-history.json`)을 사용하며 외부 유료 서비스는 쓰지 않는다.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 구현 완료 후 — `audit-data`(단어장·첨삭 기록 연동 및 미션 상태 조회의 무결성 점검) · `audit-contract`(미션 조회 API 요청·응답 규약 및 하위 호환성 점검)

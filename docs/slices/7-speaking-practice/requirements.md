# 조각 7 — speaking-practice (2026-10-29 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- 조각 ai-feedback 의 **[마이크로 말하기]** 는 한 문장만 듣고 끊긴다. 두세 문장을 이어 말하려면 문장마다 버튼을 다시 눌러야
  해서, 말하기 연습이 「짧게 한 마디」에 머문다.
- 말하는 동안 화면에 아무 글자도 보이지 않는다 — 말을 마칠 때까지 제대로 알아듣고 있는지 모른다.
- 첨삭 노트의 교정 문장 · 추천 표현을 글로만 본다. 원어민이 어떻게 소리 내는지 들어 볼 길이 없어, 말하기 연습이 「고쳐진 글을
  읽는 것」에서 끝난다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(PC · 스마트폰에서 말하기를 연습하는 1인 학습자)
- 시나리오:
  1. **[마이크로 말하기]** 를 누르고, 오늘 한 일을 두세 문장으로 쉬었다 이어 가며 영어로 말한다.
  2. 말하는 동안 입력창 아래 미리보기 줄에 알아듣는 중인 글자가 흐리게 보이고, 한 문장이 확정될 때마다 입력창에 붙는다.
  3. **[말하기 종료]** 를 누르고 입력창의 글을 확인 · 고친 뒤 **[문장 첨삭받기]** 를 누른다.
  4. 첨삭 노트에서 교정 문장 옆 **[듣기]** 를 눌러 원어민 발음으로 듣고, 따라 말해 본다. 추천 표현 · 핵심 표현 예문도 각각
     **[듣기]** 로 듣는다.

## 성공 기준

- **[마이크로 말하기]** 를 한 번 누른 뒤 사이에 쉬며 두 문장 이상을 말하면, **[말하기 종료]** 를 누를 때까지 확정된 문장이 모두
  입력창에 들어간다(지금은 첫 문장 뒤 끊긴다).
- 말하는 동안 아직 확정되지 않은 글자가 입력창 아래 미리보기 줄에 보이고, 확정되면 미리보기 줄에서 사라지고 입력창에 붙는다.
- 브라우저가 침묵 등으로 듣기를 스스로 끝내면, 그때까지 확정된 글자는 입력창에 남고 버튼은 **[마이크로 말하기]** 로 돌아온다.
  다시 누르면 이어서 뒤에 붙는다.
- 음성으로 넣은 글이 1,000자에 닿으면 듣기를 멈추고 「최대 1,000자」 안내를 보인다. 입력창은 1,000자를 넘지 않는다.
- 첨삭 노트의 교정 문장, 추천 표현 2 ~ 3개, 핵심 표현 예문마다 **[듣기]** 버튼이 있고, 누르면 그 영어를 미국 영어(en-US)
  목소리로 읽는다. 읽는 중에 다른 **[듣기]** 를 누르면 앞 소리가 멈추고 새 것을 읽는다. 이전 첨삭 기록을 눌러 연 첨삭 노트도 같다.
- 읽는 중에 **[마이크로 말하기]** 를 누르면 읽기가 멈춘 뒤 듣기가 시작된다(앱 소리를 내 말로 알아듣지 않게).
- 소리 읽기를 지원하지 않는 브라우저에서는 **[듣기]** 버튼이 보이지 않고, 첨삭 · 단어장 담기는 그대로 된다.
- PC 서버 모드와 스마트폰 단독 앱 모드 둘 다에서 위가 똑같이 된다. 기존 시험 20개가 그대로 통과한다.

## 하지 않을 일

1. 발음 · 억양 점수를 매기지 않는다 — 말한 것을 글자로 바꿔 첨삭하는 데 머문다(조각 ai-feedback 하지 않을 일 1 과 같다).
2. 녹음한 소리 파일을 저장하거나 학습 기록에 남기지 않는다.
3. 유료 음성 인식 · 음성 합성 서비스(Google Cloud, OpenAI 등)를 쓰지 않는다.
4. 단어장 복습 카드 · 오늘의 미션 화면에는 **[듣기]** 를 달지 않는다 — 첨삭 노트에만 단다.
5. 읽기 속도 조절(천천히 듣기) · 목소리 고르기는 넣지 않는다.

## 제약

- 스택 · 비용: 브라우저 내장 음성 기능(Web Speech API — 음성 인식 · 음성 합성)만 쓴다. 비용 0원. 서버 · 첨삭 요청 응답
  구조는 바꾸지 않는다.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 닫기 전 — `audit-internal`(화면만 바뀌는 조각이라 데이터 · 계약 · 자격증명 층의 감사 대상이 없다. 요구사항의
  하지 않을 일 1 ~ 5 와 앵커볼트를 코드가 지켰는지 본다)

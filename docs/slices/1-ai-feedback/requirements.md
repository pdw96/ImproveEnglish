# 조각 1 — ai-feedback (2026-10-27 착공)

요구사항이다 — **무엇을 · 왜.** 어떻게 · 경계는 같은 폴더의 `design.md`, 대안이 있던 결정은 ADR.

## 문제

- 혼자 영작문이나 말하기 연습을 할 때, 내가 쓴 문장이 문법적으로 맞는지·원어민이 보기에 어색하지 않은지 즉시 확인하기 어렵다.
- 모르는 표현을 한국어로 섞어 적거나 마이크(음성 인식)로 말한 문장을 바로 자연스러운 영어 표현으로 교정받고, 이전에 첨삭받은 내역을 한곳에서 다시 찾아보고 싶다.

## 핵심 사용자와 시나리오

- 사용자: 개인 영어 실력을 키우려는 저자 본인(1인 학습자)
- 시나리오:
  1. 웹 화면을 열고 입력창에 영어 문장(모르는 단어는 한국어 혼용 가능)을 타이핑하거나, **마이크 버튼**을 눌러 영어로 말한 내용을 글자로 변환해 입력한다.
  2. **첨삭받기** 버튼을 누르면 AI(Google Gemini)가 문장을 분석해 화면에 결과를 보여준다:
     - ① 어색하거나 틀린 부분 교정 및 쉬운 이유 설명
     - ② 원어민이 자주 쓰는 자연스러운 추천 표현 2~3가지(상황·뉘앙스 설명 포함)
     - ③ 외워두면 좋은 핵심 단어·표현 요약
  3. 방금 받은 첨삭 결과는 내 PC에 자동으로 저장되어, 화면 아래 **이전 첨삭 기록 목록**에서 언제든 클릭해 다시 볼 수 있다.

## 성공 기준

- 글자(키보드) 입력과 마이크(브라우저 음성 인식) 입력 두 가지 방식으로 문장을 입력하고 10초 이내에 구조화된 첨삭 결과(교정·이유, 추천 표현 2~3개, 핵심 표현 요약)를 화면에서 확인할 수 있다.
- 영어와 한국어를 섞어 입력해도(예: `I want to 퇴근하다 early today`) 의도를 파악해 자연스러운 영어 문장으로 교정해 준다.
- 첨삭 완료 즉시 내 PC에 기록이 자동 저장되며, 브라우저를 새로고침하거나 다시 열어도 이전 첨삭 기록 목록이 그대로 유지된다.

## 하지 않을 일

1. 녹음된 음성 파일 자체의 억양·발음 점수 평가 기능은 넣지 않는다(음성을 글자로 변환해 문장·표현을 첨삭하는 것에 집중).
2. 첨삭 결과에서 뽑은 단어·표현의 복습 주기(SRS) 알림 및 퀴즈 기능은 이번 조각에서 만들지 않는다(2번 조각 `vocab-review` 범위).
3. 일일 학습 목표 달성률 및 연속 학습일(스트릭) 통계는 이번 조각에서 만들지 않는다(3번 조각 `study-routine` 범위).

## 제약

- 스택 · 비용: 무료 제공량이 넉넉한 Google Gemini API(`gemini-2.5-flash`)를 사용하며, API 키는 코드에 적지 않고 환경변수(`.env` 파일의 `GEMINI_API_KEY`)로만 읽는다.
- 리뷰 한도: 2회차를 넘기면 소유자(저자)가 직접 판정한다.
- 감사 회차: 구현 완료 후 PR 머지 전 — `audit-secrets`(Gemini API 키 환경변수 분리 및 노출 여부 점검) · `audit-contract`(앵커볼트인 AI 첨삭 요청·응답 데이터 구조 규약 일치 점검)

## 닫으며 (2026-10-27)

- **달성한 것**:
  - 글자(한영 혼용) 입력과 마이크(브라우저 음성 인식) 입력을 통해 문장을 넣고, ① 교정 문장·이유, ② 자연스러운 추천 표현 2~3개, ③ 핵심 단어·표현 요약의 3단 카드를 화면에서 바로 확인하는 흐름을 완성했다.
  - 첨삭 결과가 내 PC(`data/feedback-history.json`)에 최신순으로 자동 저장되고, 새로고침 후에도 이전 기록 목록에서 클릭해 다시 볼 수 있음을 실제 브라우저 화면에서 확인했다.
  - API 크레딧 소진(HTTP 402/429) 상황에서도 학습 흐름이 끊기지 않도록 내장 스마트 코치 폴백을 함께 구성했다.
- **검증 및 감사**:
  - 자동 시험(`tests/test_app.py` 5개 항목) 통과 및 `audit-secrets`(회차 1) · `audit-contract`(회차 2) 부적합 0건으로 통과.
